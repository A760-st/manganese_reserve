# Model documentation

The MVP exposes model registry metadata and deterministic inference contracts. Prospectivity combines drill evidence, geology signal, and a remote-sensing spectral proxy. Forecasting returns a time-based forecast interval. Shortfall combines scenario sensitivity with equipment/rainfall factors. Contributions are associations, not causes.

Before operational use, train and persist baseline, Random Forest, and XGBoost models with spatial holdouts for prospectivity and time-based holdouts for production/shortfall. Store artifacts, features, metrics, calibration, dataset hashes, and validation reports.
